# Loan Approval Prediction using Machine Learning

## Project Overview
This project predicts whether a loan application will be approved based on applicant details.

## Dataset
Loan Prediction Dataset from Kaggle.

## Features Used
- Applicant Income
- Loan Amount
- Credit History
- Education
- Marital Status
- LoanIncomeRatio (Feature Engineering)

## Machine Learning Models
- Decision Tree
- Random Forest
- Gradient Boosting

## Evaluation Metrics
- Accuracy
- F1 Score

## Result
Gradient Boosting performed best with highest F1 score.

## Business Impact
This system helps banks reduce loan default risk and automate loan approval decisions.
